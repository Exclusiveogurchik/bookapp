# Лист — личная PDF-библиотека

Русская PDF-читалка для компьютера и телефона. Устанавливается как PWA в отдельное окно браузера. React + TypeScript + Tailwind CSS, PDF.js, Dexie/IndexedDB. Бэкенда, регистрации и загрузки книг на сервер нет.

## Запуск

Нужны Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Для проверки офлайн-режима:

```sh
npm run build
npm run preview
```

PWA работает на `localhost` или HTTPS. Откройте приложение онлайн один раз, дождитесь уведомления о готовности к офлайн-чтению и установите через меню Chrome/Edge «Установить приложение». Это веб-приложение в отдельном окне, не установщик EXE. В Safari доступны системные способы добавления веб-приложения.

## Возможности

- Несколько PDF через кнопку или drag & drop; отдельная обработка ошибок каждого файла.
- Метаданные и обложка первой страницы; редактирование названия, автора, полки, тегов и статуса.
- Поиск по метаданным, тегам и проиндексированному тексту; сортировка и фильтры.
- Удобное чтение извлечённого текста и оригинальные страницы с ленивым рендерингом, текстовым слоем, зумом, pinch и двойным нажатием.
- Пять тем, включая автотему; поля, размер и семейство шрифта, межстрочный интервал, выравнивание, локальный OpenDyslexic.
- Перелистывание по исходным страницам PDF и непрерывная прокрутка с ограниченным окном страниц; режим фокуса, зоны касания и линейка чтения.
- Оглавление PDF; если его нет, эвристическое обнаружение заголовков при индексации.
- Автосохранение номера страницы и относительной позиции; закладки, выделения четырёх цветов и заметки, переход к странице, Markdown-экспорт.
- Резервная копия JSON **с PDF-файлами**, заметками, словарём и статистикой. Проверка формата и связей до атомарного импорта, сохранение остальных книг. Настройки и API-ключ не экспортируются.
- DictionaryAPI (определения английских слов) и MyMemory (en ↔ ru), ручное редактирование и локальные карточки повторения.
- Web Speech API: голос, скорость, переход на следующую страницу, таймер сна; подсветка слов, если системный голос выдаёт события границ слов.
- Учёт активного времени, перелистываний, слов на перелистанных страницах, серия дней, цель, графики за 7/30 дней.
- PNG-карточки цитат в пяти стилях; системный Web Share, если поддерживается, иначе скачивание.
- Опциональная помощь Anthropic для выбранного фрагмента. Пользователь вводит свой ключ в настройках; текст отправляется только по нажатию. Модель указана в `src/features/Study.tsx` и может быть заменена.

## Архитектура

```text
src/
  App.tsx                   навигация, темы, установка и обновление PWA
  components/ui.tsx         диалоги, поля, пустые состояния
  features/
    Library.tsx             импорт, поиск, карточки, редактирование
    Reader.tsx              чтение, позиция, поиск, выделения, фокус
    PdfPage.tsx              один PDF-canvas и текстовый слой
    ReaderSettings.tsx      настройки чтения
    Notes.tsx               выделения, закладки, Markdown
    Study.tsx               словарь и опциональный Anthropic
    Speech.tsx              Web Speech API
    Vocabulary.tsx          карточки повторения
    Stats.tsx               статистика и графики
    QuoteCard.tsx           генерация PNG на Canvas
    Settings.tsx            резервная копия, установка, API-ключ
  lib/
    db.ts                   таблицы Dexie, транзакции
    types.ts                модель и настройки
    pdf.ts                  PDF.js, импорт, фоновая индексация
    reflow.ts               эвристики строк, переносов и абзацев
    backup.ts               валидация и перенос данных
    i18n.ts                 начальный словарь русского интерфейса
  workers/reflow.worker.ts  обработка структуры текста вне UI
scripts/prepare-assets.mjs   локальные ресурсы PDF.js для офлайн-работы
tests/                      unit и браузерные проверки
```

Файлы PDF хранятся в отдельной таблице, чтобы изменения карточек не перечитывали двоичные данные. PDF.js использует собственный worker. Объединение строк и обнаружение абзацев вынесены во второй worker. Индексация идёт по одной странице, сохраняет результат и возобновляется при следующем запуске. Читалка открывается до полного завершения индексации. Оригинал рендерит только текущую страницу; прокрутка текста держит небольшое окно страниц.

## Проверки

```sh
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

CI выполняет эти проверки. Браузерные сценарии создают PDF программно: импорт, 501 страница, текст/скан/повреждённый файл, позиция после перезагрузки, выделения, резервная копия, оригинал, мобильная ширина и офлайн. `CHROMIUM_EXECUTABLE` позволяет использовать уже установленный Chromium.

## Ограничения и сохранность

- Reflow — эвристика для текстовых PDF. Многоколоночные страницы, таблицы, формулы и порядок текста могут потребовать оригинального режима. OCR не входит в приложение. Защищённые паролем PDF следует предварительно сохранить без пароля.
- Страницы в режиме перелистывания соответствуют страницам исходного PDF; это не повторная вёрстка под каждый размер экрана.
- В оригинале выделения сохраняют цитату и страницу; точное повторное окрашивание поддерживается в reflow. Если PDF меняет пробелы, цитата оригинала может не совпасть с извлечённым текстом.
- Позиция — номер страницы и относительная доля прокрутки. При изменении шрифта или размера окна она сохраняет приблизительное место, а не пиксельную координату.
- OpenDyslexic из пакета содержит латинские символы; для отсутствующих глифов, в том числе кириллицы, браузер использует запасной шрифт.
- Полнотекстовый поиск охватывает только уже проиндексированные страницы. Библиотека показывает до 60 совпадающих страниц; поиск внутри книги — до 500 совпадений.
- Статистика — ориентир. Время считается только в активной вкладке, пока с последнего действия прошло не более минуты. Слова — текст страниц, перелистанных на соседние; возврат на ту же страницу в одной сессии повторно не засчитывается. Оценка времени до конца использует 220 слов/мин и размер текущей страницы.
- Большие JSON-копии формируются в памяти, поэтому для библиотек на гигабайты их лучше делать по мере наполнения; квота зависит от браузера. JSON с base64 больше исходных PDF примерно на треть.
- IndexedDB привязана к браузеру, профилю и адресу приложения. Очистка данных сайта удаляет библиотеку. Сделайте резервную копию перед сменой адреса или браузера.
- Для словаря, перевода и Anthropic нужен интернет. Внешние сервисы могут применять лимиты, отказать в запросе или изменить доступность. Ключ Anthropic хранится в localStorage; используйте личный профиль браузера. Платные запросы выполняются напрямую с клиентского устройства.
- Инфраструктура для переводов начата в `i18n.ts`; интерфейс пока только русский, для нового языка нужно перенести остальные подписи в словарь.

## Размещение

Результат `npm run build` — каталог `dist`. Его можно разместить на любом статическом HTTPS-хостинге. `base: './'` позволяет использовать подкаталог. GitHub Actions проверяет код и сохраняет `dist` как артефакт; автоматического публичного развёртывания нет.

Документация интеграций: [PDF.js](https://mozilla.github.io/pdf.js/), [Dexie](https://dexie.org/docs/), [Vite PWA](https://vite-pwa-org.netlify.app/), [DictionaryAPI](https://dictionaryapi.dev/), [MyMemory](https://mymemory.translated.net/doc/spec.php), [Anthropic](https://platform.claude.com/docs/).
